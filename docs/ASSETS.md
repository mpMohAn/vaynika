# Asset pipeline

Vaynika's **final** identity must remain consistent across gameplay sprites and cutscenes: face, hairstyle, eyes, proportions, skin tone, armor structure and restrained gold palette.

Production sequence:
1. Approve a single full-body character master (royal and warrior variants separately).
2. Approve orthographic side/front/back poses at a common scale.
3. Produce movement, jump, attack, block, hurt and idle sprite sequences.
4. Export transparent PNG/WebP spritesheets and frame metadata.
5. Check silhouette, foot baseline, hand/sword grip, clipping, and frame continuity.
6. Replace procedural placeholders only after QA.

Art direction: detailed cinematic 2D anime, Deccan-inspired architecture, no supernatural effects. The game's original creative assets are CC BY 4.0; track licenses of all external sources.
